# Les bancs qui parlent

Site vitrine d'un projet fictif pour Roquebrune-Cap-Martin : des bancs publics équipés d'un bouton qui, comme au musée, lance une anecdote locale murmurée à la personne assise.

Projet réalisé dans le cadre d'un exercice de prise de parole, sans lien avec la mairie.

Ouvrir `index.html` dans un navigateur pour voir le site.
